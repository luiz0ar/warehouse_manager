# Warehouse Manager - Backend (MVP)

Spacial Optimization Engine for Coffee warehouses operating in **Shadow State**.

## System requirements
- Python >= 3.12
- PostgreSQL 18+ (Container Docker `warehouse_manager`)
- Redis 8+ com AOF (Container Docker `warehouse_manager_redis`)

## Environment configuration
Copy the file `.env.example` to `.env`:
```bash
cp .env.example .env
```
